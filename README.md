# Hospital Integration API

API backend desenvolvida em **Node.js** com arquitetura em camadas para gerenciamento e cruzamento de dados entre sistemas hospitalares, exames (padrão DICOM via `AccessionNumber`), pedidos médicos e documentos anexados.

## 🚀 Tecnologias Utilizadas
* **Node.js** & **Express** (API REST)
* **Jest** & **Supertest** (Testes Automatizados)
* **Docker** & **Docker Compose** (Containerização)
